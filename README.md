# NeuroFocus Cognitive Training

A browser-based cognitive-practice prototype with short interactive exercises for reaction time, attention, working memory, inhibition and task switching.

## Problem

Many cognitive-training concepts are difficult to understand without trying them. The project explores how several familiar exercise patterns can be turned into an approachable, mobile-friendly web experience with immediate feedback.

## Solution

NeuroFocus groups several short browser games in one interface. Each exercise has a clear start state, interaction loop and result screen so users can practise and compare their own attempts.

## How it works

- Includes reaction-time, visual-search and Stroop-style inhibition exercises.
- Includes working-memory and task-switching activities.
- Tracks the current round and shows immediate performance feedback.
- Runs entirely in the browser with no account or backend.

## Tools and technologies

- React 18
- JavaScript and JSX
- HTML and Tailwind CSS
- Netlify for static hosting

The prototype does not use an external API.

## Development approach

I independently defined and built the project after encountering popular-science content about cognitive exercises. I combined ideas such as the Schulte table, sequence working-memory practice, selective-attention tasks and other short exercises into one browser experience for everyday practice.

For this public portfolio version, AI assistance was used to review claims, repair external dependencies, improve documentation and test the main interaction flows. I remained responsible for the concept, exercise selection, product direction and final decisions. The public description deliberately avoids medical, diagnostic or guaranteed performance-improvement claims.

## Impact and result

The result is a functional multi-exercise prototype suitable for demonstrating interactive frontend implementation. No user study or measured cognitive benefit has been established, so this project should be presented as a secondary portfolio piece rather than a validated health product.

NeuroFocus is an educational interaction prototype. Results reflect only the current exercise session and do not constitute medical advice, diagnosis or a general assessment of cognitive ability.
